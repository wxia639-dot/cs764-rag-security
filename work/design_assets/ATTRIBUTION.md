# Design references

The background `ikb-dot-gradient` comes from [op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill), `assets/screenshot-backgrounds/style-b/ikb-dot-gradient.webp`. Its original AGPL-3.0 licence is included as `LICENSE-guizang.txt`.

The native editable PowerPoint layouts are adapted to the existing 14-slide research content, using the Guizang Swiss grid, type hierarchy and layout rhythm as design references. This is a PPTX adaptation, not the skill's HTML presentation runtime. The content, experimental data and speaker notes are unchanged.

Additional design reference: [PPTX Rich anti-monotony guide](https://github.com/frdeange/pptx-skill/blob/main/guides/anti-monotony.md). No third-party generator code is executed or redistributed.
